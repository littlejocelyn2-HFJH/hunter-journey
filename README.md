# 〈獵人〉山林旅程｜九年級國文（康軒版 瓦歷斯‧諾幹）

學生以 iPad 或電腦操作的單頁學習網頁，前測＋三個部分一條旅程：

0. **前測**：5 題四選一（檢索 2、推論整合 2、省思評鑑 1），後端計分；第 6 題選出全文重點並寫原因（開放題，不計分）。交出後不能修正。
1. **頭燈與鏡頭**：課文第一～十五段分成 4 個段落群；選鏡頭（廣角／中距／微距）、用頭燈照亮線索、句型鷹架寫一段想法。
2. **獵人的遊戲**：真假獵人轉盤 × 哲學反駁之箭（含臺灣黑熊、SDG 15／SDG 10），準度由後端判定，寫下反駁理由。
3. **森林明信片**：寫給山林裡失落、猶豫的「我」；依原創比例自動貼郵票、蓋郵戳；可下載圖卡、複製學習歷程，交出後產生個人報告書。

## 一、開啟 GitHub Pages

Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 **main / (root)** → Save。等 1～2 分鐘後網址生效。

## 二、部署 Apps Script 後端（收資料）

1. 建一個新的 Google 試算表 → **擴充功能 → Apps Script**。
2. 刪掉預設內容，貼上本 repo 的 `apps-script/Code.gs`。
3. **第 8 行**改成你的教師密碼（10 字以上、英數混合）。維持 `change-me` 時教師功能一律無法登入。
4. （選用）第 11 行 `CLASSES` 填班級名單，例如 `['901','902','903']`，學生填錯班級會被擋下。
5. 把老師另外收到的「**答案區塊**」（含前測與第二部分）貼在「答案區」的兩行註解之間（GitHub 上故意留空，學生翻不到答案）。
6. **部署 → 新增部署作業 → 類型：網頁應用程式**，執行身分「我」，存取權「所有人」→ 部署，授權。
7. 複製 `/exec` 結尾的網址，貼進 `config.js` 的 `sheetApi`（或交給 Claude 填入並推上去）。

直接打開 `/exec` 網址看到 `{"ok":true,...}` 是正常的，那是後端。`answersReady:true` 表示前測與第二部分答案都已貼好。

### 之後如果改了 Code.gs

重新貼上程式 → **再改一次第 8 行密碼、再貼一次答案** → 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不變。

## 三、老師檢視

- 試算表會自動出現兩個工作表：
  - **前測紀錄**：每人一列，含 1～5 題選項（答錯標 ✗）、三個層級得分、全文重點選擇與原因。
  - **作答紀錄**：每次交出一列，可直接篩選；含用時、字數、靶心、郵票、三部分文字。
  - **程式資料（請勿編輯）**：給程式讀取。
- 成績頁 `#scores`：學生只看得到旅程進度榜；老師登入後才有作答紀錄、需要留意的紀錄、各說法分析、鏡頭分布、學生診斷（報告書）、公布解答、開放重做、刪除單次、清除班級、匯出 CSV、匯入成績碼、大屏入口。
- 大屏 `#screen`：淺色底、大字，每 15 秒更新；只顯示全班統計，不顯示用時與個別內容。

## 注意事項

- 每個班級座號只能交一次；需要重交時，老師在作答紀錄按「開放重做」。
- 「用時偏短」「書寫偏少」只是提醒（門檻可在教師區調整），請老師確認。
- 學生報告書預設不顯示第二部分解析；全班完成後，勾選「公布解答」才會顯示。
- 無法連線時學生會拿到一段「成績碼」，老師可在教師區匯入。
- 密碼連續錯 5 次會暫停登入 10 分鐘。用公用電腦看完請按「登出」。
- `config.js` 未設定時為本機模式，只供介面試用，不計分、不收資料。
- 學生資料在 Google 試算表；密碼與答案只在 Apps Script，GitHub 上沒有。
